# Jars/

Coloque aqui os `.aar` dos módulos nativos `vision-ocr-chinese`,
`vision-ocr-japanese`, `vision-ocr-korean` e `vision-ocr-devanagari`. Na raiz do
repositório, rode:

```bash
./gradlew exportMauiAars
```

Os `.aar` não são versionados (são build output) — por isso esta pasta só
existe no clone graças a este README.
